# london-dynamic-congestion-pricing

![London's Congestion Charge](ccz.jpeg)
London's Congestion Charge is a flat daily fee, even though traffic and air quality change hour by hour. A dynamic charge could help minimise congestion, reduce pollution and keep costs down for drivers, but it needs to know what the next few hours will look like. This project forecasts congestion, NO₂ and PM₂.₅ 1, 3 and 6 hours ahead using machine learning, tests the forecasts on unseen data, and uses a multi-objective optimiser to test whether those forecasts can support dynamic road pricing.
